# remenberall · 飞书驱动的间隔重复记忆系统

> *I want to remember everything that interests me.* — 记住一切我感兴趣的。

每天读过的文章、消息，看过就忘？`remenberall` 把你想记住的东西变成复习卡片，
按照**遗忘曲线（SM-2 自适应间隔）**在飞书里定期提醒你，让你真正记住。

**交互全在飞书**：在私聊里给机器人发一段文字 → AI（DeepSeek）提炼成「问题→答案」卡片 →
你点按钮确认 → 系统按记忆曲线在每天 07:00 / 18:00 推给你复习 → 点「记住了/模糊/忘了」反馈 →
间隔自适应调整。本地只有一个常驻后端进程，飞书是唯一前端。

## 特性

- 🧠 **SM-2 自适应排程**（Anki 经典算法），复习历史全量落库，预留升级 FSRS
- ✍️ **AI 提炼草稿 + 你确认**：不收藏，只记住你真正在意的
- 📱 **卡片交互**：两阶段复习（先想答案 → 对答案 → 反馈），全部按钮操作
- 🔄 **仅重读模式**：有些条目只推摘要、不出题
- ⏰ **定时推送**：默认 07:00 / 18:00 两波，每日上限防堆积
- 🛡️ **密钥保护**：DeepSeek / 飞书密钥只存环境变量，日志脱敏，永不入库
- ☁️ **云端常驻**：阿里云 Docker 部署，断网不断提醒
- 💾 **每日备份**：自动导出到固定的飞书在线文档

## 架构

```
┌──────────┐   发文字/点按钮    ┌───────────────┐   HTTPS   ┌────────────┐
│ 飞书 App │ ◄──────────────► │ 阿里云后端进程  │ ───────► │ DeepSeek   │
│ (你的手机)│                    │ (Python 常驻)  │ ◄─────── │ (提炼卡片) │
└──────────┘  卡片推送/提醒     └───────┬───────┘           └────────────┘
                                       │ SQLite（数据）+ 每日备份到飞书文档
```

## 目录结构

```
app/
  config.py      环境变量加载（密钥不入库）
  db.py          SQLite schema（entries / cards / review_log / app_config）
  sm2.py         SM-2 间隔重复算法
  due.py         到期队列 / 复习反馈 / 确认入库
  ai/            DeepSeek 抽取（预留多格式解析入口）
  feishu/        卡片构建 + 消息发送 + WS 长连接事件处理
  daemon.py      常驻进程（定时推送 + 备份）
  backup.py      导出 SQLite → 固定飞书文档
  cli.py         运维命令行
tests/           SM-2 与到期队列单元测试
```

## 快速开始

### 1. 准备飞书应用（一次性）

按 [FEISHU_SETUP.md](FEISHU_SETUP.md) 在飞书开放平台创建自建应用、开启机器人、
配置事件（**长连接模式**）与卡片回传，拿到 `app_id` / `app_secret`。

### 2. 配置

```bash
cp .env.example .env      # 填入真实密钥
chmod 600 .env            # 权限收紧（服务器上）
```

### 3. 本地跑通

```bash
pip install -r requirements.txt
python -m app.cli status            # 检查配置
python -m app.cli daemon            # 启动常驻进程
# 在飞书里给机器人发一条消息 → 自动记录你的 open_id
python -m app.cli push-test         # 验证推送链路
```

### 4. 部署到阿里云

见 [DEPLOY.md](DEPLOY.md)：Docker 一键起。

## 使用

| 操作 | 方式 |
|---|---|
| 录入知识 | 给机器人发一段文字（文章/笔记/感悟） |
| 确认草稿 | 草稿卡上点 `确认 / 仅重读 / 丢弃 / 重写` |
| 复习 | 每日自动推送，或发 `/复习` 随时来一轮 |
| 反馈 | 复习卡上点 `记住了 / 模糊 / 忘了` |
| 抽查 | `/抽查` 随机抽测 |
| 查看 | `/列表` `/统计` |
| 管理 | `/仅重读 <id>` `/删除 <id>` `/编辑 <id>` `/帮助` |

普通文字 = 内容；`/` 开头 = 命令。

## 配置项（.env）

| 变量 | 默认 | 说明 |
|---|---|---|
| `DEEPSEEK_API_KEY` | — | DeepSeek 密钥（必填） |
| `FEISHU_APP_ID` / `FEISHU_APP_SECRET` | — | 飞书自建应用凭据（必填） |
| `PUSH_SLOTS` | `07:00,18:00` | 每日推送时段 |
| `DAILY_CAP` | `15` | 每时段推送上限 |
| `TIMEZONE` | `Asia/Shanghai` | 时区 |
| `BACKUP_TIME` | `03:10` | 每日备份时段 |
| `BACKUP_DOC_ID` | 自动创建 | 备份文档 ID（一般不用填） |
| `DATA_DIR` | `./data` | SQLite 数据目录 |

## 安全

- 所有密钥只从环境变量读取，代码/仓库零密钥
- 日志脱敏：不打印密钥、请求体
- 备份文档只含知识库数据，不含任何凭据
- `.env` 已加入 `.gitignore`，即使建公开仓库也不会泄露
